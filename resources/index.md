## Useful Links

Databases, machine-learning tools, and simulation resources we find useful for computational materials research.

### Databases and Datasets

| Resource | Description |
|---|---|
| [Materials Project](https://next-gen.materialsproject.org/materials) | Open database of computed materials properties |
| [OQMD](https://oqmd.org/) | Open Quantum Materials Database of DFT-computed properties |
| [JARVIS](https://jarvis.nist.gov/) | NIST's Joint Automated Repository for Various Integrated Simulations |
| [OMat24](https://huggingface.co/datasets/fairchem/OMAT24) | Open Materials 2024 dataset of DFT calculations for ML models |
| [MatPES](https://matpes.ai/) | Materials Potential Energy Surface dataset (PBE and r2SCAN) for training universal ML interatomic potentials |

### Machine-Learned Interatomic Potentials

| Resource | Description |
|---|---|
| [MACE](https://github.com/ACEsuit/mace) | Higher-order equivariant message-passing neural network force fields |
| [NequIP](https://github.com/mir-group/nequip) | E(3)-equivariant neural network interatomic potentials |
| [Allegro](https://github.com/mir-group/allegro) | Strictly local equivariant interatomic potentials that scale to large systems |

### Simulation Tools

| Resource | Description |
|---|---|
| [VASP Wiki](https://www.vasp.at/wiki/index.php/The_VASP_Manual) | Manual and tutorials for the Vienna Ab initio Simulation Package |
| [Materials Square](https://www.materialssquare.com/) | Web-based platform for materials simulations |
