# {% include icon.html icon="fa-solid fa-atom" %}AI4Mat Demo

**AI4Mat** is a CDFM project on AI-driven discovery of functional materials.
This demo showcases predicted structures along with their computed properties — density of states (DOS), electronic band structure, and ab initio molecular dynamics (AIMD) trajectories — computed with DFT as implemented in VASP.
Select a structure to explore it interactively.
